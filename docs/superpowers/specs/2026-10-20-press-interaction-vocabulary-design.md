# 按压词汇表 / 结果图形 / 奖励时刻 —— 设计（2026-10-20）

> 需求原文：「添加按键交互功能，不是文字交互而是图像和动画交互，让软件更加高级」。
> 实现细节与行号见 [`docs/modules/interaction-fx.md`](../../modules/interaction-fx.md)；本文只记**决策与依据**。
> 顺序说明：用户当时要求「先装机」，所以本文按"实现完成后补记"的方式写，装机凭据一栏待真机跑完补。

## 1. 判据（用户选的三条，另一条主动没选）

1. **响应快且不掉帧** —— 可证伪形式：`pointerdown → 下一帧 ≤100ms`；rAF 间隔中位 ≤20ms；按下前后 `getBoundingClientRect()` 逐位相等。
2. **全站只有一套按压词汇** —— 可证伪形式：数值只在一处定义；练习面 `active:scale` 计数为 0；`data-press` 覆盖数只许涨不许跌。
3. **结果不靠文字** —— 可证伪形式：反馈图形节点出现、`[data-sonner-toast]` 仍为 0、未判定/不计分的节点不许出现"成功"图形。

未选的第 4 条（"真机用过一遍才算"）没有作废：装机仍是交付门槛，只是不作为唯一判据。

## 2. 边界（用户逐条定的）

- **不做振动**：不动 `AndroidManifest`、不加插件，三形态保持一致。
- **手段预算**：地基只用合成器属性 + 已在壳里的 framer-motion；只允许**两个奖励时刻**用程序化 canvas。不新增依赖、不新增图片/动画资产。
- **第一刀范围**：地基 + 三个高频练习页（背单词闪卡 / 视频精听 / 语块接龙）。

## 3. 路线选择

| 路线 | 取舍 |
|---|---|
| A 只动样式层（`:where(button):active` 一条规则） | 零调用点改动，但纯 CSS 拿不到触点坐标（做不了从手指扩散的涟漪）、会误伤 tab/开关/卡面整张、结果层与奖励时刻管不着 |
| **B `<Button>` 基座一处改动 + 一处指针事件委托（选定）** | 395 处组件按钮自动生效；306 处裸按钮补一个 `data-press` 属性即可；涟漪需要 JS 时才建节点；结果层与奖励层各自独立可测 |
| C 逐页 `whileTap` / `AnimatePresence` | 与判据②正面相反，306+395 处调用点改动，每处都要包 `LazyFramerProvider`（真机翻过整页崩的案） |

## 4. 关键决策与被证据推翻的三处

| 决策 | 依据 |
|---|---|
| 缩放走 CSS 独立 `scale` 属性而不是 `transform` | 现有代码在按钮/卡面上已写 `transform: translate(...)`，两者互相覆盖；独立属性按 translate→rotate→scale 各自合成 |
| 抬起用定长 tween 170ms，不用 spring | 本仓早先实测：spring 要衰减到亚像素才算完，尾巴≈400ms（`verify-vocab-cards.mjs:364` 钉着） |
| ~~涟漪用 `currentColor`~~ → 按底色亮度挑墨/白两档 | **被像素推翻**：浅底上墨色像"变灰/禁用"，深底上白色几乎看不见 |
| ~~奖励粒子从视口中心炸开~~ → 从触发元素中心、半径封顶、单色系 | **被像素推翻**：铺满整屏压住正文，违反"配图不许压过正文" |
| ~~reduced-motion 靠 CSS 藏~~ → 委托层直接不建节点 | **被像素推翻**：藏的那版 DOM 里仍留着涟漪节点（无谓的 DOM 抖动） |
| 涟漪装在自有 `.fx-ripple-host` 层，不给按钮加 `overflow:hidden` | 后者会掐掉焦点环与内部浮层 |
| 结果层用纯 CSS，不引 motion 组件 | `useFramerMotion()` 带 provider 前置条件，铺到 N 个渲染点就是 N 处崩面（`verify-overlay-fit` ⑦ 逐个宿主点名） |
| 奖励层全站唯一出口，挂在 `src/index.tsx` | 复用 `<Toaster />` 那条已验证的"剥注释全仓扫描只许一处"口径；`celebrate()` 拿不到 context 时 no-op，**绝不回退成 toast** |
| 卡面整张不给按压缩放 | 与手势拖拽共存，缩一下 + 手指一动就抖 |

## 5. 交付分档

- **第一档（本次）**：词汇层 + 委托 + 基座 + 奖励层 + 结果图形件；接线覆盖 9 个练习面（闪卡/快速闪卡/每日学习/短语闪卡/中译英/纠偏重考/词汇页外壳/语块卡/视频精听）+ 闪卡的连击环与两个奖励时刻。
