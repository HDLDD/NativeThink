# NativeThink 产品方向：以“母语思维”为主轴

- 日期：2026-10-24
- 状态：方向已定，分阶段落地
- 依据：[native-thinking-bibliography.md](./research/native-thinking-bibliography.md)
- 现有实现：[think-in-english.md](./modules/think-in-english.md)

## 1. 一句话方向

把“母语思维”从一句口号变成一个**可诊断、可训练、可迁移、可复习、可测量**的模式系统，让 `/think` 成为整款软件的主轴；词汇、语块、句子、跟读、写作、对话都围绕它提供素材与证据。

## 2. 为什么是现在

现有 `/think` 已经有四个单句级练习和一个模式训练闭环，但学习单位仍然偏“一句话”：

- 单句反馈能指出问题，却不容易累计成“我在哪类建构上反复出错”。
- 词汇/语块/跟读各自有进度，但没有一个共同的“表达质量”层。
- 用户能感到“学到了”，却看不到“在新场景里用出来了没有”。

模式训练闭环已经验证了最小可行路径：对比 → 识别 → 迁移 → AI/自评 → SM-2。下一步不是再加一个 tab，而是把这条路径做成全站的主轴。

## 3. 定义与边界

### 3.1 这里的“母语思维”指什么

指 **thinking for speaking / construal**：在开口前对以下问题做出的默认选择。

- 谁做主语：话题还是动作发出者？
- 什么放句尾：已知信息还是新信息？
- 动作由谁承担：动词还是名词化？
- 关系要不要明说：意合还是形合？
- 断言力度：事实、推断还是可能？
- 礼貌怎么调节：直接、缓冲还是给替代方案？

它是**一套可切换的默认值**，不是民族性格，也不是口音模仿。

### 3.2 不做什么

- 不做“变成美国人”的训练；目标是清晰、自然、语域适配、可被自然理解。
- 不把“中式英语”当羞耻标签；用“中文默认 → 英语默认”的对比语言。
- 不承诺“21 天重塑思维”；只承诺在训练过的模式和新情境上可测量的迁移。
- 不把文化层面的平均差异推成个体标签；所有模式都要用学习者数据验证。
- 不把“不一样”一律判错；区分不可理解、语域不匹配、可接受变体。

## 4. 证据 → 设计原则

| 证据 | 设计原则 |
|---|---|
| thinking for speaking：概念化阶段先做选择 | 先训“怎么想”，再训“怎么编码”；对比卡先于识别题 |
| 概念迁移分层：类别、建构、映射 | 每个模式写清“中文默认建构 / 英语默认建构”，不只给正确例句 |
| 注意是入口，产出才促成加工 | 识别题只是入口；每个模式必须有自由产出 |
| 技能习得：陈述性 → 程序性 → 自动化 | 同一模式多次、跨情境、带反馈；不靠一次讲解 |
| 纠正性反馈：聚焦、可理解、可执行 | 反馈给“模式证据 + 一处改写”，不写泛泛评语 |
| 提取练习 + 间隔 | pattern 级 SM-2；复习时先回忆，再看提示 |
| 迁移适当加工 | 迁移题与真实场景同构；新情境、新词、延迟三种变式 |
| 远迁移证据弱 | 主指标放在 near/mid transfer 与延迟保持，不吹“通用思维” |
| 母语者标准受质疑 | 评分维度用自然度、清晰度、语域适配，不用“像不像母语者” |

## 5. 模式地图（12 个，四层）

| 层 | id | 名字 | 一句话 |
|---|---|---|---|
| 信息结构 | `subject-first` | 让主语站出来 | 中文先给话题，英文先给主语和动作 |
| 信息结构 | `end-focus` | 把重点放到句尾 | 新信息、长成分放句尾，避免头重脚轻 |
| 信息结构 | `fill-references` | 该说的代词别省 | 中文常省主语/宾语，英文要补出指代 |
| 动词与焦点 | `verb-driven` | 把动作还给动词 | 少用“进行/处理/做…的…”，直接用动词 |
| 动词与焦点 | `result-state` | 把结果说进句子里 | 中文“把…V得…”常对应英文 V + O + adj 或单个动词 |
| 逻辑与信息 | `make-logic-explicit` | 把逻辑说清楚 | 中文靠意合，英文把因果/转折/条件说出来 |
| 逻辑与信息 | `hedge-stance` | 把断言调到可讨论 | 预测和评价用 may/might/tend to，不把推断说成事实 |
| 逻辑与信息 | `be-concrete` | 少说大词，多说具体 | 用具体动作、数字、结果替代空泛形容词 |
| 语域与语用 | `soften-disagreement` | 先铺缓冲再否定 | 先承认/缓冲，再给不同意见 |
| 语域与语用 | `polite-request` | 请求要有台阶 | 命令改成 could/would + 缓冲 + 理由 |
| 语域与语用 | `compliment-response` | 赞美先接住 | 先感谢/接受，再补充，不先自贬 |
| 语域与语用 | `register-shift` | 先看场景再选正式度 | 邮件/论文可以正式，聊天/会议要直接；名词化不是一律错 |

### 5.1 后续候选（13–15）

| 层 | 候选 id | 为什么值得加 |
|---|---|---|
| 动词与焦点 | `motion-path` | 中文路径补语 vs 英文路径卫星/介词，是 TFS 研究最成熟的领域 |
| 逻辑与信息 | `stance-verbs` | argue / claim / suggest / show 的力度差异，直接服务写作与口语 |
| 信息结构 | `cohesion` | 句间代词、连接、主题句；从“单句思维”走到“段落思维” |

## 6. 学习闭环

```
诊断 → 对比 → 识别 → 首稿 → 反馈 → 改写 → 反馈 → 新场景 → 最终反馈 → 间隔复习 → 闭卷/延迟标识
                                      ↘ 跨模块证据（未来：写作 / 对话 / 纠偏本）
```

1. **诊断**：12 道跨模式识别题，输出四层 profile；不评分、不排名，只给“默认倾向 + 待练模式”。
2. **对比**：中文默认说法 vs 英语默认说法 + 一条可执行线索。
3. **识别**：三选一，三个选项都语法成立；每项标“最直接 / 也能说但更绕 / 这里不地道”。
4. **迁移**：中文场景 → 自由写英文；AI 按 rubric 判定，失败回落自评。
5. **反馈**：并排“你的表达 / 参考表达”，给 why、判断线索、AI 证据。
6. **间隔复习**：pattern 级 SM-2；失败回队尾，最多 2 次。
7. **闭卷迁移**：`repetitions >= 2` 时收起“先想三步”，让用户先自己组织（desirable difficulty）。
8. **延迟探测**：7/21/60 天的新情境题，测保持与迁移，而不是当天表现。
9. **跨模块证据**：写作/对话/纠偏本里是否自发用出模式；只作为证据，不自动改分。

## 7. 产品结构：主轴与支流

| 层 | 模块 | 角色 |
|---|---|---|
| 主轴 | `/think` 模式训练 | 模式地图、今日模式、三稿训练、复习、薄弱聚焦 |
| 素材 | `/vocabulary`、`/chunks`、`/sentences` | 提供词、语块、句子的地道样例；不单独承担“思维” |
| 证据 | `/writing`、`/conversation`、`/shadowing` | 真实产出面；未来把模式使用情况回流到诊断 |
| 入口 | 首页 | 主卡从“待复习单词”逐步转为“今日模式 + 今日迁移” |

**首页重心的迁移顺序**：先加“今日模式”卡（不删词汇卡）→ 观察点击与完成 → 再把词汇/语块降为支撑位。不要一次性推翻现有首页。

## 8. 指标

### 8.1 主指标

| 指标 | 定义 | 说明 |
|---|---|---|
| Near transfer pass rate | 同一模式、新场景的迁移通过率 | 现有 `transferPasses / transferAttempts` 已是雏形 |
| Delayed retention | 7/21/60 天后的复习通过率 | 需要延迟探测；不能用当天数据代替 |
| Spontaneous use | 写作/对话中自发出现目标模式的比率 | 未来跨模块；需要人工/AI 标注 |
| Calibration | 自评“会”与 AI 判定的一致度 | 迁移前三级自评，只统计没把握/有把握的预测 |
| Error-type shift | 话题结构/名词化/搭配/语用错误占比变化 | 比“总分”更能说明迁移 |

### 8.2 辅助指标

- 识别正确率（入口，不是结果）
- 复习完成率、到期清空率
- 首次迁移用时（流利度/自动化）
- 每层已掌握数 / 到期数

### 8.3 不作为主 KPI

- 学习时长、连续天数、卡片数。它们能被“刷”出来，不能证明迁移。

## 9. 路线图

### Phase 1（本次落地）

- 模式库 8 → 12，四层元数据与“模式地图”。
- 概览按层分组，显示每层已掌握/到期。
- 闭卷迁移：`repetitions >= 2` 收起“先想三步”。
- 守卫、模块文档同步。

### Phase 2（本次落地）

- **思维体检**：12 道跨模式识别题，输出四层 profile 与建议模式；不调 `grade`、不写“思维分”，只存汇总。
- **迁移变式**：每个模式 5 条迁移（3 新情境 + 2 换措辞）；三稿闭环（首稿 → 改写 → 新场景），距首次练习 ≥7/21/60 天时标延迟探测，同样闭卷。
- **自评校准**：迁移前先选“没把握 / 一般 / 有把握”，反馈显示判断是否准确；焦点卡累计“校准 x/y”。
- **自由训练**：任选一个模式或混合练得最少的 5 个，不受到期与每日新名额限制。
- **改写快练**：60 道由识别题派生的改写题，10 题一组；看参考自评，不写 SM-2，专门补日常练习量。
- **真实任务前后测**：写 80–120 词真实邮件；AI 标出 5 个目标模式的 used/missing；前后测只对比模式使用与缺失，不造总分。
- **口头任务**：两条 60–90 秒客户电话；本地录音、回听、自评，到 90 秒自动停止；不上传、不接 ASR、不造发音分。
- **薄弱报告**：按 lapses → 迁移失败率取 Top 3，带最近反馈；点行进详情。
- **模式详情**：中文默认 / 英语默认 / 线索 / 反例与改法 / 当前排期，只读，可直接开练。
- **模式库摊开**：15 个模式按四层卡片墙默认展开，到期优先；支持层/状态筛选，每张卡直接练或看详情。
- **断点续练**：三稿会话的队列、阶段、题号、草稿与反馈存本地，刷新或离开后从原处继续。
- **首页今日模式**：有进度才渲染；到期/延迟计数、下一模式、近 7 天迁移柱，点进 `/think`。
- **趋势与复测**：每日迁移/校准累计 + 7 天柱；体检历史按日去重，概览显示复测序列。
- **跨模块证据**：纠偏本按写作/对话/检测来源计数，关键词归因到模式，作为待诊断候选。
- **15 个模式**：新增 `motion-path`（路径要单独说出来）、`stance-verbs`（态度动词要选准）、`cohesion`（关系要说出来），各 5 识别 + 5 迁移；体检扩到 15 题、改写扩到 75 题。
- **长文 / 对话 / 无中文源**：长邮件、客户投诉对话、英文图表描述，外加 3 条实景看图任务（车站赶车 / 服务台 / 团队白板）；图表用内联 SVG、实景图存 `public/images/think/*.webp`，草稿本地保存，AI 或手动自查，不写 SM-2。
- **AI 额外出题**：按现有模式库生成 2–3 个目标模式的新任务，只进练习列表，不进入掌握判定。
- **后续可做**：短视频/音频无中文源任务、音素级口头评测。

### Phase 3（跨模块）

- 首页“今日模式 + 今日迁移”主卡。
- 写作/对话/纠偏本按模式归因，作为“待诊断”候选。
- 学习记录页增加“模式迁移”折线，而不是只显示时长。

### Phase 4（扩展）

- 13–15 个模式：`motion-path`、`stance-verbs`、`cohesion`。
- 无中文源提示：图片/短视频/音频直接表达，复用同一套模式库与 rubric。
- AI 生成额外迁移场景（不进入 master 判定，只用于防背诵）。

## 10. 话术与边界

| 场景 | 推荐说法 | 避免说法 |
|---|---|---|
| 产品定位 | “把中文默认换成可切换的英语默认” | “消除中式思维” |
| 目标 | “清晰、自然、语域适配” | “像母语者一样” |
| 迁移 | “在新场景里用出来” | “学完就会自动迁移” |
| 反馈 | “这次用上了/还没用上这个模式” | “你的英语很差” |
| 文化 | “中文常用话题—评论结构” | “中国人都这样想” |
| China English | “可理解、合语域的变体” | “不一样就是错” |

## 12. 风险

- **内容成本**：每个模式 5 识别 + 5 迁移 + 15 条逐项说明；质量比数量重要，宁少勿滥。
- **过度概括**：模式是倾向，不是规律；文案必须留出个体差异。
- **AI 判定波动**：rubric 要窄、反馈要可执行；失败一律回落自评，不误报格式异常。
- **指标幻觉**：当天通过率不等于迁移；没有延迟数据前，不要宣称“长期有效”。
- **首页改动风险**：先加卡、不删卡；用数据决定是否重排。
