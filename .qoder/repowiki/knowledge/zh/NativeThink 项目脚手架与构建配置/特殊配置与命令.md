- 开发：`npm run dev`（启动 Vite dev server，内置 `scripts/dev.mjs` 与跨域代理）
- 构建 Web：`npm run build:web`（输出至 `dist/client`，自动复制 `index.html` 为 `404.html`）
- 打包 Android APK：`npm run package:apk`（需安装 Android SDK/Gradle，会先执行 `ensure-web-build`、TTS 语音校验、`capacitor copy android` 并调用 `gradlew assembleDebug`）
- 打包桌面：`npm run package:desktop`（基于 Electron Packager）
- 全量打包：`npm run package:all`（并发 apk + desktop）
- 版本管理：`npm run version:apk-bump` 写入 `android/version.properties`，Vite 构建期强制读取该文件，缺失则抛错拒绝构建
- 预提交钩子：`npm run prepare` 安装 `precommit` 钩子执行 `npm run lint`（typecheck + eslint）
- 需要 `scripts/.apikey`（gitignored）提供出厂内置 API Key，否则 `__FACTORY_API_KEY__` 为空字符串
