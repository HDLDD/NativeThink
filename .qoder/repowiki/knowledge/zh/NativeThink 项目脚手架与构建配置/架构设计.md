本模块为整个 NativeThink 项目的工程根，职责是统一构建与发布流水线：
- 构建层：`vite.config.ts` 通过自定义插件 `serveBundledModels`（dev 下暴露 `models-bundled/` 给 WASM）、`mockVirtualCapabilities`（适配 Cloudflare virtual module）、`fixHtmlPlaceholders`（替换 `{{appName}}` 等占位并剥离 Lark 平台埋点脚本）扩展 Vite；`base`、`resolve.alias`（`@`→src、`@shared`→shared）、`server.proxy` 统一代理 `/api/*` 到 `https://nativethink.pages.dev`。
- 多端产物：`capacitor.config.json` 将 `dist/client` 作为 Android WebDir 并启用 `https` scheme；Electron 入口由 `package.json` 的 `main` 指向 `electron/main.mjs`；Cloudflare Pages 通过 `wrangler.toml` 指定 `pages_build_output_dir = "dist/client"` 并绑定 KV namespace 用于 auth/sync/passage 存储。
- 脚本编排：`package.json` scripts 以 `node scripts/*.mjs` 串联各阶段——`dev` 走 `scripts/dev.mjs`，`build` 走 `bash scripts/build.sh`，打包链路 `package:web → package:apk → package:desktop → package:all` 分别产出 Web 静态资源、Android APK 与 Electron 安装包；大量 `verify:*` 脚本覆盖 TTS 语音校验、bundle 体积预算、云同步卫生等专项验证。
- 类型与样式：`tsconfig.*` 三件套分离 node/app 类型检查；Tailwind v4 + shadcn/ui（`components.json` 中 style=new-york、iconLibrary=lucide）提供 UI 组件库；ESLint 9 通过 `eslint.config.mjs` 统一 lint。
- 依赖方向：构建脚本与 Vite 插件仅依赖 Node API，业务代码通过 `__FACTORY_API_KEY__` 注入出厂密钥并通过 `virtual:capabilities` 桥接平台能力。
